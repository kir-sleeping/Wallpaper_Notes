# CR001 — 默认快捷键值修正

**日期：** 2026-07-30
**触发来源：** decision-tree-verify-a1 代码一致性审查报告
**修改类型：** 修复（决策树与代码默认值不一致）

## 背景

子 Agent 在进行 A1 path 代码一致性审查时发现默认快捷键值在三处不一致：

| 来源 | 旧值 |
|------|------|
| 决策树 B3 statement | Ctrl + Shift + A |
| config.py:74-75 fallback | Ctrl + Shift + N |
| config.json（实际使用） | Ctrl + Alt + A |

## 决策

W主理确认统一使用 **Ctrl + Alt + A**，理由：

> Ctrl + Shift + A 和 Ctrl + Shift + N 与浏览器的一些快捷键冲突。

## 修改内容

### 1. config.py
- `get_hotkey()` 文档字符串：`(['ctrl', 'shift'], 'n')` → `(['ctrl', 'alt'], 'a')`
- `modifiers` fallback 默认值：`["ctrl", "shift"]` → `["ctrl", "alt"]`
- `key` fallback 默认值：`"n"` → `"a"`

### 2. 决策树 B3
- statement 中默认值：`Ctrl+Shift+A` → `Ctrl+Alt+A`

## 验证

- `config.json` 中已存储真实值为 `["ctrl", "alt"]` + `"a"`，本次修改使代码 fallback 与 config.json 一致
- 重启应用后首次启动（无 config.json）将 fallback 到 Ctrl + Alt + A

## 后续

- config.json 中的实际值仍是用户原始设置，本次改动不影响已启动用户
- 此修改保证：**新安装/重置配置的用户**也会自动获得无浏览器冲突的快捷键
