# 📋 Wallpaper_Notes 使用指南

> 把便签贴在桌面上。
> 不需要打开任何软件，退到桌面就能看。

---

## 🚀 基本操作

| 操作 | 方式 |
|------|------|
| **快速呼出窗口** | 快捷键 `Ctrl+Alt+A`（可在设置中修改） |
| **进入编辑** | 双击便签内容区 / 按 `Enter` / 托盘菜单「进入编辑」 |
| **保存并退出编辑** | 再次双击 / 连点第三下 / 按 `Esc`（都会自动保存） |
| **切换便签** | 点击标签行上的便签名 |
| **新建便签** | 点击标签行最右端的 `+` |
| **重命名 / 删除便签** | 右键便签名 → 重命名 / 删除 |
| **移动便签到分组** | 右键便签名 → 移动到… |
| **展开 / 收起分组** | 点击分组名；或鼠标悬浮 0.3 秒「瞥一眼」（移开自动收起） |
| **分组管理** | 右键分组名 → 新建便签 / 新建子文件夹 / 重命名 / 删除 |
| **移动窗口** | 按住标签行（便签名或空白处）拖动 |
| **调整窗口大小** | 拖拽窗口边缘 |
| **切换便签（滚轮）** | 在标签行上滚动滚轮：上滚 = 上一张，下滚 = 下一张（到首张/末张就停住，不循环，避免快速滚动时切过头） |
| **自动跟随** | 切到的便签若被边缘裁掉，标签行会**自动滑过去**把它露出来；分组拉出时视口跟着一起平移，而不是动画结束再跳一下 |
| **横向滚动标签行** | `Shift` + 在标签行上滚动滚轮（一般用不到，切换时会自动跟随） |
| **显示 / 隐藏窗口** | 双击托盘图标 |
| **设置** | 右键托盘图标 → 设置 |
| **退出** | 右键托盘图标 → 退出 |

> 补充：右键标签行右端的 `+` = 新建文件夹；右键标签行空白处 = 新建便签 / 新建文件夹。

## 📖 Markdown 语法

预览模式支持下列语法。**标题等块级语法不需要用空行隔开**，直接写下一行即可：

| 语法 | 效果 |
|------|------|
| `# 标题` ~ `###### 标题` | 六级标题，字号依次递减（`#` 最大） |
| 普通文字 | 正文，**单个换行即换行显示**，空行分段 |
| `- 项目` / `* 项目` | 无序列表 |
| `1. 项目` | 有序列表 |
| 行首缩进 2 个空格 | 列表嵌套（可多级） |
| `- [ ] 项目` / `- [x] 项目` | 任务列表，显示为 ☐ / ☑ |
| `> 引用` | 引用块，可多行、可嵌套 |
| `**粗体**` / `*斜体*` | **粗体** / *斜体* |
| `~~删除线~~` | ~~删除线~~ |
| `` `行内代码` `` | 行内代码 |
| 三个反引号包裹 | 代码块，可写 ```` ```python ```` 标注语言 |
| `[文字](https://…)` | 链接，点击后用系统浏览器打开 |
| `![说明](图片路径)` | 图片，**超宽会自动缩到便签宽度**，相对路径以该便签所在文件夹为基准。可选尺寸 `{width=300}` / `{width=50%}`；**同一行连写多张会并排** |
| 表头行 + `\|---\|---\|` 分隔行 | 表格（分隔行必须有，否则不识别） |
| `---` | 分隔线 |

**几点注意：**

- **代码块**：三个反引号独占一行开始，再独占一行结束；块内内容原样显示，不再解析语法。
- **表格**：第二行必须是 `|---|---|` 形式的分隔行；表格紧跟在文字后面可以直接写，应用会自动补断行。
- **图片**：推荐把图片和便签放在同一文件夹，写相对路径 `![说明](图.png)`；也可写绝对路径 `![说明](D:/图片/a.png)`。路径用**正斜线或反斜线都可以**（`D:\储存\Image\a.jpg` 也能显示），中文路径没问题，空格也会正常处理。**图片默认自动适应便签宽度**（大图缩小、小图保持原尺寸，不会被裁切也不用左右滚动）；想指定尺寸可在后面加大括号：`{width=300}`（像素，精确尺寸）或 `{width=50%}`（按写的时候的便签宽度定成固定尺寸：之后窗口怎么缩放图片都不再跟着等比变化，只有便签窄到放不下时才自动缩小；小图不会被放大）。**同一行连写多张图片会并排**，放不下会自动换到下一行；两张大图并排各占一半的写法：`![a](1.png){width=48%} ![b](2.png){width=48%}`
- **路径含空格**时要用尖括号包起来：`![说明](<my photo.png>)`，否则不会被识别为图片。
- **链接颜色**：默认 `#4A90D9`，可在 `theme.json` 的 `content.link_color` 修改（设置界面暂未提供该项）。
- **原生 HTML 不会生效**：写成 `<div>` 之类的标签会原样显示为文字（内容安全考虑）。
- **行首缩进 4 个空格**会被当作代码块；若只是想让文字缩进，请用 1~3 个空格。

## 📁 分组管理

`notes/` 下的**子文件夹就是分组**，可以多层嵌套。标签行上分组显示为一颗可拉开的「抽屉」胶囊，展开后其中的便签才露出。

- **新建分组**：右键标签行空白处 / 右键 `+` / 右键分组名 → 新建文件夹（或新建子文件夹）
- **放便签进分组**：右键便签名 → 移动到… → 选择目标分组
- **重命名分组**：右键分组名 → 重命名（组内便签与子分组一起跟着改名）
- **删除分组**：右键分组名 → 删除（**连同组内全部便签一起删除**，操作前会显示便签数量并确认）
- **悬停即可展开**：鼠标停在分组上 0.3 秒，抽屉自动拉开（移开自动收起），不用点击；点分组名可切换展开/收起
- **实心胶囊**：文件夹显示为主题色的实心小胶囊（可在设置里改颜色和文字色），胶囊只包住文件夹名；子便签不套任何底色，直接排在它右侧
- **展开时自动让位**：若分组里的便签在窗口里放不下，标签行会跟着抽屉拉出一起向左平移、把这个分组贴到最左侧，好让子便签尽量多露出来
- **切走会自动收回**：从分组里切到组外的便签时（点击或滚轮切换都算），这个分组自动收起；切到同组另一张则保持展开
- **顶部指示条**：每个分组胶囊顶部有一条指示条（颜色在设置里的「分组抽屉 → 文件夹条颜色」配置）。未选中组内便签时它只盖住文件夹名；一旦选中组里的某个便签，就会缓动延伸到那张便签，把「这段都属于这个分组」标出来
- **展开状态会被记住**：重启应用后自动恢复上次展开的分组（存放在 `config.json`）
- **同一层同时只展开一个分组**，展开新分组会自动收起同层的其他分组

> 也可以直接在文件资源管理器里操作 `notes/` 的子文件夹，应用会自动同步。

## 🎨 样式自定义

**右键托盘图标 → 设置**，打开设置对话框。所有视觉效果均可实时调节、所见即所得。按「应用」即刻生效且不关闭对话框，方便反复调试。
ok：保存配置并退出设置
cancel：不保存配置并退出设置
apply：保存并应用配置但不退出设置，方便调试

### ⌨️ 全局快捷键
| 选项 | 说明 |
|------|------|
| **组合键** | Ctrl / Shift / Alt / Win（可多选） |
| **按键** | A-Z、0-9、F1-F12、Space、Tab、Escape、Enter、Backspace、Delete |
| **开机自启** | 勾选后随 Windows 启动，通过注册表 HKCU\Run 实现 |

> 默认：`Ctrl+Alt+A`

### 📑 标签栏

标签页部分的完整样式：

| 选项 | 说明 |
|------|------|
| **背景色** | 标签栏底色，滑块调透明度（0%=完全不透明，100%=全透，全透可能会导致点击穿透，即被系统视作为点击到了桌面上，而非便签上，这是Windows系统层的一些特性，计划在后续版本中进行修复） |
| **文字色** | 未选中标签的文字颜色（纯色） |
| **选中色** | 选中标签的文字颜色（纯色） |
| **指示色** | 选中标签底部指示条的颜色（纯色）。只有选中的便签才显示指示条：选中时从中心向两侧缓动生长出来，取消选中时缩到一半即消失 |
| **字体** | 标签文字字体（下拉可选，支持自定义字体） |
| **字号** | 标签文字字号（8~40pt） |
| **上圆角** | 标签顶部圆角（0~30px） |

### 🗂️ 分组抽屉

标签行上文件夹胶囊（抽屉）的配色：

| 选项 | 说明 |
|------|------|
| **胶囊颜色** | 文件夹实心胶囊的颜色（默认取主题指示色；高度只比文字高 3px，宽度与顶部指示条平齐） |
| **胶囊文字色** | 胶囊里文件夹名的文字颜色（默认白色） |
| **右缘分隔线** | 分组右端竖线的颜色（收起时紧跟胶囊，展开时随子项移到最右） |
| **文件夹条颜色** | 顶部指示条的颜色（紧贴胶囊顶边、与胶囊等宽；选中子便签时像胶囊长出去一样延伸到它，未选中也不消失） |
| **新建(+)色** | 标签行右端 `+` 按钮的颜色 |
| **右缘渐隐** | 便签溢出被裁掉时的右端淡出宽度（0~80px） |

### 🔤 字体管理

添加自定义 .ttf / .otf 字体到应用中：

1. 点击「添加字体...」按钮
2. 选择 `.ttf` 或 `.otf` 文件
3. 字体自动复制到 `fonts/` 目录，注册到应用
4. 所有字体下拉列表立即出现新字体
5. 重启应用后自动加载，不丢失

## 🤖 AI 自动写入

AI 可以直接往 `notes/` 写文件，桌面自动显示：

```bash
echo "## 今日灵感\n\n- 想到了一个好点子" > notes/灵感.md
```

在 `notes/` 下建子文件夹就是建分组，AI 也能直接建：

```bash
mkdir -p notes/工作 && echo "## 本周目标\n\n- [ ] 完成报告" > notes/工作/本周目标.md
```

Markdown 语法（表格、任务列表、代码块等）AI 同样可以直接使用，详细清单见上面的「📖 Markdown 语法」。

## 🔧 注意事项

- ❌ 设置对话框中有部分参数因 bug 无法生效（不影响主要功能）
- ✅ `notes/` 目录不存在时会自动创建，无需手动新建
- ⚠️ 删除便签 = 删除对应的 `.md` 文件；删除分组会连同组内全部便签一起删除（不可恢复）
- ⚠️ 行首缩进 4 个空格会被当作代码块，只想缩进文字请用 1~3 个空格
